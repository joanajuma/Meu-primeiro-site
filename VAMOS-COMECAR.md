## 🚀 COMO USAR?

### 1️⃣ Iniciar o servidor

```bash
npm run dev
```

O site estará em: **http://localhost:5173/**

### 2️⃣ Personalizar com seus dados

Abra os arquivos em `src/components/` e altere:
- Nome da loja
- Número do WhatsApp
- Produtos
- Depoimentos
- Informações de contato

*Leia **MUDANCAS-RAPIDAS.md** para saber exatamente onde clicar!*

### 3️⃣ Adicionar suas fotos

Crie: `src/assets/images/`

Depois importe nos componentes.

### 4️⃣ Fazer build

```bash
npm run build
```

Aparecerá a pasta `dist/` pronta para hospedar.
